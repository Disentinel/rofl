# Dogfood log — the amnesiac arm (2026-08-28, same day, ~40 minutes)

Direction from Vadim: find the killer case — easy to show, widely demanded,
runnable inside the subscription within an hour, naive implementation
welcome. The answer fell out of the morning's reflection: stop fighting
context *rot* (the model generation already beat it on this slice) and
demonstrate surviving context *death* — the structural condition every
agent user knows as compaction, resume, and handoff.

## Setup

Same LIC slice, same evaluator, one new arm: **a fresh one-shot Haiku 4.5
per turn**. The agent that answers turn k has never seen turns 1..k-1 — no
conversation, no own prior replies, nothing. It receives only the rendered
ledger (~15 lines). Because no state crosses turns, all 53 turn-calls ran
as independent one-shots (three parallel waves, ~40 minutes wall-clock);
`solved_at` = first turn whose answer scores correct, later turns ignored
(a live conversation would have stopped there). One scoring rule added: an
`ANSWER:` line with no extractable number (e.g. "ANSWER: cannot be
determined") counts as an abstention, not an attempt — their evaluator
extracts nothing from it, and persistent arms abstained by omitting the
line. Full record: `bench/lic-haiku45-amnesiac.json`.

## Result: total amnesia + ledger reproduces the persistent dialogue

| sample | solved at (amnesiac) | solved at (persistent ledger) | wrong attempts (amn / pers) |
|---|---|---|---|
| 144 | 11 | 11 | 0 / 0 |
| 968 | 9 | 9 | 1 / 1 — the SAME 18.5-min fabrication at t8 |
| 158 | 8 | 8 | 2 / 2 — the same "6" at t4, "14" at t6 |
| 1190 | 8 | 8 | 0 / 0 |
| 346 | 6 | 6 | 2 / 3 — amnesiac ABSTAINED at t3 where persistent answered "36" |
| 976 | 8 | 8 | 0 / 0 |

6/6 final-correct, solve turn identical on all six samples, and the error
trace matches almost move for move — including the one fabrication, which
pins that failure on the ledger *rendering*, not on conversation momentum.
The single divergence went in amnesia's favor: at 346 t3 the fresh agent
noted "the ledger doesn't say she eats them all" and abstained, while all
three persistent arms answered 36. History added nothing on these tasks —
where it differed at all, it *hurt*.

That is the substitution claim demonstrated literally: the ledger carried
100% of the task state. Statefulness without state.

## Honest caveats

- **Cost, in this harness, went the wrong way**: 53 one-shot subagents ×
  ~26K fixed harness overhead ≈ 1.4M tokens vs ~190K for the six
  persistent conversations. The fixed per-call overhead (system prompt,
  file read) dwarfs the ~0.5KB ledger payload. The economics argument
  lives where payload dominates overhead — real sessions with 100K+
  histories — and remains to be measured there, not here.
- The near-identical error traces also say Haiku is near-deterministic on
  these inputs; the 346-t3 divergence is n=1 and could be sampling noise
  rather than a history effect.
- n=6, one run, GSM8K-easy. Substitution is shown at this difficulty; the
  claim scales only as far as tasks whose state factorizes into facts
  (see the skeleton-and-flesh discussion in the benchmark protocol's
  successor experiments).

## Why this matters for the thesis

Context rot fades with every model generation — the morning run showed the
floor already above this slice. Context death does not fade: windows end,
sessions compact, agents hand off. An agent whose working state lives in a
materialized ledger is indifferent to context death by construction — and
this run is the first mechanical demonstration, on externally authored
tasks with the suite's own scorer. The next step up in difficulty: the
same amnesiac arm on tasks the model cannot one-shot (LIC code/database),
and the open-world rendering to remove the fabrication channel.
