# Dogfood log — the Haiku pilot (2026-08-28)

Direction from Vadim: a dumb cheap test on a small model with a predictable
outcome, before the long-horizon grant benchmarks. Built `bench/pilot.ts`
(seeded generator of synthetic decide-inquiries with ground truth: stale
trap, alias trap, contested pair, pure-unknown, distractors) and ran it live
in-session: 6 episodes × 2 arms × haiku-4.5 subagents, one call per arm.

## Registered prediction — and how it failed both ways

Predicted: engine arm near-perfect (mechanical derivation), baseline
degrading on the traps. Actual first run:

- **baseline 48/48** — at toy scale (8 claims, 14 memos) Haiku 4.5 with the
  rubric in hand solves the whole thing in its head. No degradation at all.
- **engine 42/48** — all six misses the SAME trap (stale evidence counted).
  Root cause was the harness, not the model or the concept: `stale_evidence`
  was defined in an optional policy file the pilot never loaded, so the
  freshness invariant silently ran disabled. Ground truth caught it in one
  glance (`f_staleness_needs_kernel_load`; freshness now loads with the
  kernel).

After the one-line fix the engine arm replayed to **48/48 with zero new
model tokens** — extractions are data, derivation is deterministic, so
fixing rules and re-running is free. That replay property is itself a
result worth putting in the grant text.

## What this buys

- The harness works end-to-end (generator → two arms → admission-style
  ingestion → derivation → scoring) for ~330K cheap-model tokens total.
- The honest conclusion feeds the protocol: at trivial scale there is
  nothing to win — the measurable edge, if it exists, lives at scale and
  horizon (more claims, more noise, longer distances, context pressure).
  Exactly the long-horizon thesis; the pilot cannot substitute for it.
- Both arms cost the same here because each is one call; the expected
  "engine burns more tokens" effect belongs to fetch-loop settings, to be
  measured there.
