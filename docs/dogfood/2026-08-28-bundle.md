# Dogfood log — skill bundle (2026-08-28)

Session: packaging guided-formal-reasoning into a self-contained marketplace
bundle (`scripts/build_skill.ts` → `dist/guided-formal-reasoning/`).

## What worked

**1. Zero-dep discipline cashed out at packaging time.** The bundle is a
plain copy: instruction .md files at the root, engine (kernel + rules +
runtime + schemas + the synthetic fixture) underneath. No build step, no
install, no lockfile — `node --experimental-strip-types` and done. The only
excluded component is the babel-dependent scanner, by design.

**2. "Self-contained" is proven, not asserted.** The build's own smoke runs
a real pair session INSIDE the freshly built bundle (init → verdict → next
→ instruction resolution) and fails the build otherwise; the test suite
does the same from a tmpdir. Verified separately from a foreign cwd
simulating a user project: fresh frame, correct intents, instructions
resolved from the bundle root.

**3. Path-independence needed exactly two touchpoints.** The engine already
resolved its assets relative to its own files (`import.meta.url`), so the
bundle worked almost unchanged; only `instructionFor` needed a repo-vs-
bundle fallback, and SKILL.md needed the `$GFR` engine-root convention to
serve both layouts from one text. Single-source instructions — no
marketplace/repo drift to maintain.
