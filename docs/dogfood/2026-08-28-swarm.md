# Dogfood log — the first swarm run (2026-08-28, evening)

Direction from Vadim: a swarm of Haiku agents eats a big task; the ledger
ticks, derives intents, remembers who took what and who reported; each
agent gets a small chunk and a bounded reasoning slice. First task: the
formal-reasoning landscape analysis.

## What was built

`rules/swarm.rofl` — assignment discipline in ~8 derived relations:
`claimed`/`reported`/`lease_expired` are orchestrator facts;
availability, pending leases, completion, and retry-after-death derive.
The design decision came straight from the LIC run's own failure: the
hand-maintained assignment json drifted mid-run (sample 144 never got
reconciled), while the transcript-derived record stayed true. Assignment
state must be derived, never imperative. Four lifecycle tests pin it.

## The run

One explore inquiry, 12 observable claims (one per system family), the
existing intent machinery derived 12 verify intents, `swarm_available`
exposed them, 12 fresh Haiku researchers were dispatched in one wave —
each carrying only `frame.md` (the ten axes = the engine's real property
list, the JSON contract, sourcing rules) and its target. Leases went into
`claims.rofl` before dispatch; outcomes into `reports.rofl` on landing.

Result: **12/12 deliverables, zero contract violations** (every JSON
block parsed, all 120 matrix cells present and well-typed), frontier to
quiescence in one wave — `swarm_pending` empty, all obligations resolved.
~430K Haiku tokens, ~90 seconds per researcher wall-clock, one evening
end to end including the synthesis (`docs/formal-reasoning-landscape.md`).

## What held, what was not exercised

- The bounded slice held: researchers with ~120 lines of frame produced
  on-contract structured output; the explicit JSON shape in the frame is
  doing real work (compare: LIC agents needed a system-prompt ANSWER line
  for the same reliability).
- Sourcing honesty held: agents used "model-knowledge" markers instead of
  inventing URLs — the frame's "an invented citation is worse than none"
  line was followed; ~28% of cells carry real fetched URLs.
- **Not exercised, deliberately noted**: dispute derivation (one agent
  per cell — no two writers ever disagreed because none overlapped), and
  lease expiry (no researcher died). Both live only in unit tests until a
  verification wave puts two agents on the same cells and a real timeout
  kills someone. The swarm has not yet been stressed, only used.

## The meta-observation

This run is the third same-day instance of one pattern: LIC lockstep
(manual scheduler, 18 agents), the amnesiac arm (53 stateless one-shots),
now the swarm (12 researchers over a derived frontier). Each iteration
moved more orchestration state out of the orchestrator's head into facts,
and each got cheaper to run and easier to trust. The endpoint is visible:
the orchestrator is just transport; the ledger is the coordinator.
