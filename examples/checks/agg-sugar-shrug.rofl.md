# the sugar's shrugs, asked in sentences

> What a sugar form answers when what it reads has no answer: a shrug inherited from the fault, asked here in the
> answer model's own sentence, `... has no answer for the reason R with M`, which the reader reads and rofl-render
> writes (docs/aggregates.md, "Shrugs, as built" and "The sentence form, as built").

Declared as facts:

- <a id="sg_group"></a>A group G is listed

<a id="sgq_mean"></a>A group G has an open mean for R if G is listed and sgs_mean(G, some value) has no answer for the reason R with some meta.

<a id="sgq_micro"></a>A group G has an open fine mean for R if G is listed and sgs_micro(G, some value) has no answer for the reason R with some meta.

<a id="sgq_out"></a>A group G has an open turnout for R if G is listed and sgs_out(G) has no answer for the reason R with some meta.

<a id="sgq_small"></a>A group G has an open size for R if G is listed and sgs_small(G) has no answer for the reason R with some meta.

<a id="sgq_root"></a>A group G has its mean open from M if G is listed and sgs_mean(G, some value) has no answer for the reason `inherited` with a meta M.
